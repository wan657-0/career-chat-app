# AI职业规划智能体

基于讯飞星火大模型的大学生职业规划智能系统，帮助学生进行职业探索、能力自评、人岗匹配和发展路径规划。

## 功能模块

- **岗位探索**：八大专业类别，30+岗位画像，智能推荐
- **能力自评**：8维度能力评估，实时雷达图预览
- **人岗匹配**：多维度匹配分析，差距标签提示
- **发展报告**：行业趋势分析，职业路径规划，AI润色与导出
- **AI职业顾问**：在线对话咨询

## 技术栈

- 前端：HTML5 + CSS3 + JavaScript
- AI接口：讯飞星火大模型 API
- 代理服务器：Python (HTTP Server)

## 快速开始

### 环境要求

- Python 3.x
- 现代浏览器（Chrome、Firefox、Edge）

### 启动方式

**方式一：一键启动（推荐）**

双击运行 `启动服务器.bat`，浏览器会自动打开应用。

**方式二：手动启动**

```bash
# 启动代理服务器
python server.py

# 打开浏览器访问
http://localhost:8000/职业规划智能体.html
```

## API配置

1. 点击右上角"设置"按钮
2. 输入讯飞API的AppID、API Key、API Secret
3. 关闭"演示模式"
4. 保存设置

## 项目结构

```
├── 职业规划智能体.html    # 主页面
├── xf-spark-api.js       # 讯飞API封装
├── server.py             # 代理服务器
├── 启动服务器.bat         # 启动脚本
├── 使用说明.txt           # 使用说明
└── .gitignore            # Git忽略配置
```

## 注意事项

- 必须通过代理服务器访问，不能直接打开HTML文件
- API调用有QPS限制，建议避免频繁调用
- 首次使用需要配置讯飞API密钥
